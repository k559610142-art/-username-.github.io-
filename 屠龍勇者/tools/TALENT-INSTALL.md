## 安裝

1. 使用者在Supabase SQL Editor開新查詢，貼入同資料夾 **talent-system.sql完整內容**，按Run。不要貼template或catalog.json。
2. 前置為目前已安裝的server-loot、loot-batch、vault-v2與既有掉寶增量。安裝會在原函式追加天賦規則，保留未鑑定地圖與傭兵符石；失敗整筆回滾。不要重新跑舊安裝總檔。
3. 出現Success後，本機遊戲Ctrl+F5，確認更新紀錄版本20261029m，登入原帳號、完成雲端同步，再進入「天賦星盤→正式角色天賦→檢查開放」。SQL尚未安裝時，按鈕會提示未開放。
4. 若之後重建掉寶catalog或覆蓋loot_roll／loot_finish／loot_finish_batch，應再執行本增量；可重跑，不會清空已配天賦、試煉紀錄或交易紀錄。

新增三張表dragon_talent_trials／dragon_talent_state／dragon_talent_ops；不修改Supabase連線設定，不清除既有角色或道具。SQL已包含PostgREST schema更新通知。

## 正式規則

- Lv.10拿1點，Lv.20有11點、Lv.50有41點、Lv.99有90點。舊角色依目前等級直接計算，不逐次累發。
- 首次擊倒T1／2／3／4／5／7／9／11／13／15的異界地圖首領，每名角色各拿1點；合計上限100點。歷史擊殺不追溯補發，從安裝後的新規則憑證開始記錄。
- 每個主盤、星孔與星團節點都是1點。退1點扣1顆天賦石；斷線、石頭不足、切斷前置或其他驗證失敗不扣。拆一般／轉化珠不耗石；星團要先逐點退完分支才可拆珠。
- 一般怪寶珠掉率T1→T15為0.02%→0.30%、首領1%→5%、首次試煉另抽2%→10%；天賦石分別0.05%→0.50%、2%→10%、5%→20%。中間階級線性增加；無異界階級的場景依後端有效怪物等級對應。新掉率不受地圖掉寶詞綴放大。
- 所有階級皆有機會取得38款寶珠。一般70%／轉化10%／星團20%；一般魔法70%／稀有30%，星團小60%／中30%／大10%。同類主題均分。
- 一般珠與已學節點的結構化數值套用角色；轉化只改範圍內已學基礎節點；同主題核心互斥。傭兵與其召喚物可受契靈加成，魔法娃娃不受此加成。
- 孤星狙擊在線上使用地圖格距離判斷；沒有場景座標的離線／模擬戰鬥採距離4格計算。

## 照著點驗收

先按HANDOFF.md第5節備份原角色的dragonSlayer_*存檔。不要上傳新增的測試角色。

1. 本機 http://localhost:8790/ 按Ctrl+F5→進入原角色→天賦星盤；原畫應保持一致，每個節點可查看數值，隔離試玩不會動正式資源。
2. 登入／同步→檢查開放→正式配點；剩餘點數應符合目前等級與已完成試煉。點一個相連節點→配置，應扣1點且角色能力同步變化；重新進入角色仍保留。
3. 背包有寶珠時配置對應星孔→鑲嵌，背包減少同一顆；拆除後同UID回背包。星團插入後可逐點學習4／6／8個分支，未退完不能拆。
4. 有天賦石時退回一個末端節點，應退1點且扣1石；不能切斷其他已學節點。正式介面不提供免費清空。
5. 完成一個未完成的指定階級地圖首領→應增加1試煉點；同階級重複擊倒不再增加。重新登入仍保留紀錄。寶珠掉落為機率，不保證一次擊殺就取得。
6. F12→Console應無紅字；若有，將完整錯誤貼回。確認畫面與操作沒問題後才提交；之後由使用者在GitHub Desktop按Push origin發佈。
