# 大型場景與傭兵公會製作規格草案

日期：2026-11-01。狀態：已確認風格／活動方向；技術方案與數值待確認，尚未接入正式遊戲。

## 已確認

- 保留目前俯視斜角、角色動畫與黑暗奇幻美術風格。
- 大型可探索場景，不只是把舊圖片放大。使用原創場景，不複製天堂／天堂2的圖片或地圖布局。
- 公會團員為NPC，任務中能看到與玩家共同移動、戰鬥。
- 獨立討伐任務＋約10分鐘怪物入侵、防守人物或物件。
- 在本機進行戰鬥，任務結果可累積一星期批次交付伺服器，由伺服器發獎。
- 使用者同意完整內容列入製作範圍，並確認每場帶3位NPC，含玩家共4人；獎勵數值、存檔或SQL變更尚未確認。

## 現有架構實查

- scene-art.js：整體188×149格、16個約47×37格區塊；既有world-play.jpg為整圖，部分區塊共用狩獵zone。
- ui-scene.js：MAP_MON_MAX=30，怪物數依可走面積／密度決定；現有尋路與戰鬥不是大量單位專用。
- 既有傭兵系統一次一名，含WeakMap短期狀態、技能、仇恨、跟隨；不能直接複製幾個模型就當作多NPC戰鬥完成。
- 團隊副本已有場景重播，可參考動畫接線；公會任務要有真正的本機互動戰鬥，不以純重播取代。

## 大型地圖提案（尺寸是試作目標，不是效能承諾）

以32×32格分塊，繪圖只載附近區塊，遠區降低更新頻率；遊戲邏輯座標與圖片解析度分開。先沿用原有zone ID／掉落／地圖階級，新增地貌子區與出入口；需要變更分區玩法再獨立確認。

|場景|目標格數|主要地標|
|---|---|---|
|低語海島|256×256|海岸、聚落、森林、山道、礦坑入口、古墓、前哨|
|熔火群山|256×192|火山山麓、熔岩河、廢棄鍛爐、洞窟、龍穴外圍|
|沉船群島|256×256|港口、椰林、走私營地、沉船灣、堡壘、寶庫|

以目前一區47×37格比較，256×256約為38倍面積；這不代表同時增加38倍活躍怪物。其他原有場景保留並透過地圖入口連接，不刪素材／不覆寫存檔。

每區交付：原創地面分塊、物件／遮擋層、可走遮罩、入口／出生點、怪物營地、任務互動點、小地圖與世界總覽定位。防止區塊接縫、假道路與入口不可達。

## 公會小隊提案

**使用者確認的出戰範圍**：公會NPC伙伴僅於傭兵公會任務內出現及參戰。完成、失敗、放棄、離開任務時均返回公會，不跟隨玩家進入野外、村莊、異界、龍穴或其他副本；清除任務位置、仇恨、召喚物與臨時增益，不將公會隊伍能力帶到外部戰鬥。招募／成長／療養與已完成任務紀錄依規則保留，不因退出刪除。既有個人傭兵是獨立系統，不受此新增公會伙伴退場規則影響。

已確認招募方式B：初始提供3位NPC團員，其餘透過公會任務逐步招募。使用者已選初始陣容C：依玩家職業補足隊伍，提供3位互補NPC。使用者同意以基礎職業決定初始分配，二轉後保留已招募伙伴，不自動更換。定位搭配：近戰承傷→遊俠／法師／補師；遠程或法術輸出→盾衛／戰士／補師；治療支援→盾衛／遊俠／法師。使用者已同意12職業初始分配：王族／騎士／修羅／戰士→遊俠＋法師＋補師；法師／妖精／黑暗妖精／槍手／魔鬥士／惡魔→盾衛＋戰士＋補師；聖騎士／天使→盾衛＋遊俠＋法師。後續招募解鎖條件尚待確認。

NPC候選六職業：盾衛、戰士、遊俠、法師、補師、斥候；每場帶3位已由使用者確認，含玩家共4人；使用者已選A自由選隊：每場從公會NPC名單自由選3位出戰，可依任務調整職業搭配。公會NPC與現有個人傭兵分開，原傭兵永久死亡／裝備損失規則不得默默套用公會團員。

簡單指令：集合、守點、集火、撤退；獨立HP／MP、仇恨、補血、倒地與救援。任務結束還原原位置，不帶回任務怪物／臨時增益；本週未交付成果可繼續上傳。使用者已選B：NPC任務內倒地可救援，未救起者回公會後需療養，不永久死亡；使用者已選療養B：固定30分鐘，期間不能出戰，可改派其他團員；是否可提早治療尚未決定。

## 全部任務內容

### 討伐探索六種

1. 失聯採礦隊：救出3名礦工、護送出口、擊敗礦坑巨怪。
2. 毒霧中的藥草：收集解毒草、摧毀毒囊減毒、討伐蛛后。
3. 商道清剿：清三座營地、救斥候取得弱點情報、打強盜首領。
4. 古墓封印：護守三座封印的啟動過程、封住亡靈源頭。
5. 獵龍前哨：摧毀龍卵／巢穴，殘留龍卵在首領戰孵化。
6. 失落公會旗幟：取回旗幟、持旗減速、全隊護送撤離。

每種有明確成功／失敗、路線、首領／事件與可選目標；敵人／數量／難度／獎勵需另有平衡表，不以名稱清單當作已實作。

### 入侵防衛六種

1. 最後的營火：守補給核心，核心定時治療附近友軍。
2. 北境城門：兩路入侵，攔截優先攻城的巨怪。
3. 守護封印師：保護不能移動的施法者，處理遠程敵人。
4. 難民撤離：村民分批抵達撤離點，以救援達標人數判定。
5. 魔晶運輸車：沿路護車，停靠時守住怪潮。
6. 龍潮之夜：守弩炮到最後階段，弩炮協助擊退巨龍。

建議10分鐘：0～2分鐘試探、2～5分鐘專攻目標敵人、5～8分鐘多路精英、8～10分鐘首領／援軍。明確區分守滿時間與擊倒首領的勝利條件；保護目標死亡立即失敗。暫停／背景／讀檔不得跳過戰鬥取得存活時間，時序沿遊戲時鐘並驗證。

### 其他活動七種

- 團員個人委託：NPC故事與分支目標。
- 公會遠征：三段地圖，途中補給／救援／追擊選擇，隊伍狀態延續。
- 每週懸賞首領：固定弱點與特殊招式。
- 訓練演習：不消耗正式補給、不發正式獎勵。
- 公會重建：醫療室／訓練場／情報所，解鎖功能；不先添加永久戰力。
- 救援信號：任務內可選支線，救NPC小隊。
- 精英挑戰令：加速、限制補給、雙首領等修飾，不同於現有異界詞綴。

## 一週累積與安全結算

建議週任務冊：討伐4、防衛2、個人委託1、遠征1。未定重置時區／期限／跨週寬限／失敗重試次數，需使用者確認；允許提前批次交付。

伺服器領取帶任務ID、角色、規則版本、固定種子、隊伍／裝備快照、獎勵上限與有效期的唯一憑證。本機保存行動輸入與可重播的固定步長戰鬥結果；伺服器驗證憑證／重算／限制再發獎。客戶端加密或雜湊本身不能證明勝利，離線回報也無法完全證明真人操作。

必須先證明模擬可跨環境重播，並量測整週多場驗證的CPU／RAM／紀錄大小；不得直接在既有Micro資料庫無上限同步重算。採限量小批次、可續傳與獨立任務佇列，是否需要獨立驗證服務視實測決定。批次可部分成功、逐張防重領；伺服器確認後才發獎／清本機待交付紀錄，關頁重試不重領。

提案獎勵：公會聲望／代幣／團員培養材料；具體數值、可交易性與既有金幣裝備經濟尚未授權。

需確認後才實作：新增player公會成員／週任務／待交付記錄與SAVE_SCHEMA遷移；新增伺服器任務憑證／收據／公會帳本／RPC。SQL獨立新檔，由使用者執行，不改雲端連線設定、不自動執行正式SQL。

## 製作與驗收順序

完整功能列入範圍，按依賴施工：分塊／鏡頭與尋路→大型原創場景→多NPC真實戰鬥→12種任務與7種活動→固定種子驗證→一週批次結算→正式接入。每步保留可操作隔離預覽，不以拆步驟縮減承諾內容。

效能先測手機同場30／60／90敵人、3／5友軍，記錄平均與95百分位幀耗時、尋路、記憶體與長時間穩定性；活躍上限依測試定，不預先承諾90隻通過。測地圖接縫、全路徑、救援／護送卡路、保護目標仇恨、背景與讀檔、重複回報、跨角色、跨週、伺服器拒絕與斷線續交，原狩獵／異界／傭兵／掉寶均需回歸。
