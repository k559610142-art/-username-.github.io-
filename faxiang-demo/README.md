# 法相天地：獨立演武場

此目錄是「凡塵修仙傳」的獨立動畫原型，不會取代或載入正式遊戲首頁，也不讀寫遊戲存檔。

- `index.html`：演武場，可預覽召喚、攻擊、消散、三方向女修動畫及元神外觀對應。
- `gallery.html`：14款法相圖鑑，可篩選男性／女性。
- 七種偏好：金、木、水、火、土、雷、風，對應正式遊戲12種元神。
- 女玩家固定女性法相，男玩家固定男性法相；沒有獨立選擇法相性別的選項。
- 「玩家性別（預覽）」只模擬玩家角色；正式整合時應讀取遊戲角色的 `player.gender`。

在儲存庫根目錄執行 `python -m http.server 8780`，開啟 http://localhost:8780/faxiang-demo/index.html 或 gallery.html。
若儲存庫已經以 GitHub Actions 發布 Pages，獨立頁路徑為 `/faxiang-demo/index.html`、`/faxiang-demo/gallery.html`。

## 素材與功能限制

女角走路6×3、攻擊8×3，皆含正面／側面／背面；施法7×3為三組前斜面招式，不是三方向。男角先使用原遊戲靜態立繪，尚無男性動畫圖集。角色素材經影像工具去背／重建，可能與原圖有細節差異。

法相是獨立透明PNG，以整圖升起、浮動、透明度及Canvas粒子呈現；尚非逐幀或骨架的肢體／髮絲／衣袖動畫。男女法相共用屬性、能力定位及演出時間，不增加性別數值差異。

此原型沒有正式解鎖、資源消耗、冷卻或戰鬥結算功能。元神選單可自由預覽，不代表玩家取得資格。正式整合須由可信後端驗證元神、角色性別與技能使用，不能信任瀏覽器提交的性別或傷害。

## 驗證與交付

`python faxiang-demo/tests/browser_check.py` 使用Playwright與系統 `/usr/bin/chromium`，檢查桌機／手機尺寸、四階段、男女配對、12元神對應、觸控、圖鑑與存檔隔離。尚未在真機Safari／Android上驗證。

`python faxiang-demo/package.py` 可選擇產生離線單檔HTML與ZIP；圖片只嵌入一次，輸出檔很大，無需提交到儲存庫。

架構與後端整合契約見 `ARCHITECTURE.md`，造型對照見「法相設計.md」。
