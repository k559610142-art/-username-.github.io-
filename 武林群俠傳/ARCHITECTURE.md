# 浪跡江湖：架構文件

即時制 2D 地圖武俠 MMORPG 框架，單機版，存檔放在瀏覽器 localStorage。
系統結構參考傳統武俠線上 RPG 的類型玩法：五項屬性、外功／內功、卸勁／化勁、修為、強化、自動練功。
名稱、門派、地名、美術、劇情、數值都是原創，**不可照搬任何商業遊戲的素材或名稱**。
資料夾名稱 `武林群俠傳/` 只是暫用，之後建議改成原創名稱。

> 修改前先讀第 1、2 節，再用 `## ` 標題找到要改的章節；改完回來更新對應章節。

## 1. 專案結構

| 檔案 | 內容 |
|---|---|
| `index.html` | 版面、全部 CSS、`<script>` 載入順序 |
| `data/config.js` | 常數、屬性清單、品質、兵器系、強化表、經驗／修為公式、共用小函式 |
| `data/skills.js` | 四大門派（內功、心法）、三系兵器外功、`SKILL_INDEX`／`skillDef()` |
| `data/maps.js` | 地圖（練功區、首領、傳送點、城鎮房屋與 NPC）、怪物數值公式、障礙物產生與碰撞 |
| `data/items.js` | 裝備名稱與屬性、丹藥、掉落 |
| `data/avatar.js` | 原創 SVG 紙娃娃人物外觀、轉成圖片快取給畫布用 |
| `data/state.js` | 玩家存檔 `G`、屬性計算、升級、存讀檔、離線收益 |
| `data/world.js` | 世界暫態 `W`、進出地圖、移動與繞路、怪物 AI、自動練功、每幀世界更新 |
| `data/combat.js` | 即時戰鬥：普攻、外功、內功聚氣、命中閃避、卸勁化勁、擊殺結算、死亡、丹藥 |
| `data/render.js` | canvas 地圖繪製、小地圖、點擊輸入 |
| `data/ui.js` | 建角畫面、HUD、快捷欄、各視窗（含 NPC 視窗）、所有 onclick 頂層函式 |
| `data/main.js` | 啟動、主迴圈、鍵盤快捷鍵 |
| `.claude/launch.json` | 本機預覽伺服器（port 8781，根目錄為上一層） |

## 2. 載入順序與依賴關係

`config → skills → maps → items → avatar → state → world → combat → render → ui → main`

- 全部是一般 `<script>`，函式與常數都是全域。
- 後面的檔案可以用前面的；執行期互相呼叫（例如 state 的 `gainExp` 呼叫 ui 的 `addLog`、world 的 `floatText`）沒問題，因為都在載入完成後才執行。
- 兩個全域狀態：`G`＝玩家存檔（會存檔），`W`＝世界暫態（不存檔，進地圖時重建）。
- 主迴圈（main.js `loop`）：每幀以 50ms 為一步跑 `worldTick` → dirty 時重畫 HUD 靜態部分與視窗 → `render` 畫地圖 → `renderHud` 更新血條與冷卻 → 每 10 秒自動存檔。

## 3. 版本號

`config.js` 的 `GAME_VERSION` 與 `index.html` 每個 `?v=` 要一起換（格式 `YYYYMMDDx`）。
**改任何 JS 都要換**，否則瀏覽器會吃舊快取（開發時已遇過一次：一半新檔一半舊檔）。
目前版本：`20261102j`。

## 4. 屬性與數值公式（state.js `calcStats`）

五項屬性，每級 5 點，可勾「依門派自動配點」（`SECTS[x].autoAttr` 比例）：

| 屬性 | 效果 |
|---|---|
| 臂力 str | 外功攻擊 +2 |
| 身法 agi | 閃避 +0.12%、攻速 +0.25%、聚氣加速 +0.3% |
| 體魄 con | 氣血 +14、防禦 +0.4、卸勁 +0.08%、回血 +0.005%/s |
| 真元 qi | 內功攻擊 +2、真氣 +8、化勁 +0.06% |
| 悟性 wu | 命中 +0.15%、會心 +0.12% |

- 基礎：氣血 120＋每級門派成長、真氣 60＋成長、外功 16＋3/級、內功 14＋3/級、防禦 5＋1.6/級、命中 90、會心 5、閃避 3、回血 0.8%/s、移動 150 px/s。
- 上限：會心 60、閃避 45、卸勁 50、化勁 50、攻速 60、聚氣加速 60。
- 普攻間隔＝1.5 × 兵器係數 ÷ (1＋攻速%)。
- 傷害＝攻擊 × 倍率 − 防禦 × 0.5，浮動 ±10%，會心 ×1.6。
- 命中機率＝clamp(命中 − 閃避, 20, 99)%。
- **卸勁**：受到外功（近身）攻擊時，有卸勁% 機率傷害減半。**化勁**：受到內功（遠程）攻擊時，傷害 ×(1 − 化勁%)。
- 經驗：`expNeed(lv) = 25·lv^2.3 + 30·lv`；等級上限 99。死亡扣當級所需經驗 5%。
- 修為：打怪獲得，用來學／升武學（`skillCost`）與心法（×2）。

## 5. 門派與武學（skills.js）

- **內功**（`SECTS[x].skills`）：門派專屬，遠距離，大多要聚氣 `cast` 秒（身法可縮短），用內功攻擊計算。在「武學」視窗修練。
- **心法**（`SECTS[x].inner`）：被動，每重加成，最多 10 重。
- **外功**（`OUTER_SKILLS`）：刀／槍／爪／徒手四系，四派共用，貼身立即出手，用外功攻擊計算；**要裝備對應兵器才能用**。在城鎮「武館教頭」學。
- 效果欄位：`mul` 倍率、`perLv` 每重加成、`hits` 段數、`aoe` 範圍、`dot` 中毒、`stun` 暈眩、`heal` 回血%、`buff`（`xiejin`／`dodge`／`atkPct`／`defPct`）、`mustCrit`。
- 解鎖等級：每系 1／8／18 級。

| 門派 | 定位 | 內功 | 心法 |
|---|---|---|---|
| 玄霄觀 | 遠程內功爆發 | 掌心雷、玄霄劍氣、五雷正法 | 內功攻擊、真氣 |
| 鐵衣門 | 坦、卸勁 | 金鐘護體、獅子吼、不動如山 | 氣血、卸勁 |
| 百草谷 | 毒、自療 | 青蛇針、回春術、百毒瘴 | 真氣、回血 |
| 無影樓 | 閃避、會心 | 飛影鏢、迷蹤步、攝魂術 | 閃避、會心 |

| 兵器 | 射程 | 速度係數 | 外功 |
|---|---|---|---|
| 刀 | 58 | 1.1 | 劈山式、旋風斬、斷浪刀 |
| 槍 | 92 | 1.25 | 突刺、橫掃千軍、蛟龍出海 |
| 爪 | 50 | 0.85 | 裂石爪、鎖喉手、千手連環 |
| 徒手 | 46 | 1.0 | 衝拳（建角就會） |

新增武學：在對應陣列加一筆，`SKILL_INDEX` 會自動建立。

## 6. 地圖（maps.js）

- `MAPS`：柳溪鎮（城鎮）→ 青石山道（1～10）→ 落霞竹林（10～22）→ 黑風寨（22～34）→ 寒潭古洞（34～47），順序在 `MAP_ORDER`。
- 每張野外地圖：`mobs` 練功區（固定等級、數量、中心、半徑、是否主動攻擊 `aggro`、攻擊類型 `dtype`）＋ `boss`（5 分鐘重生）＋ `portals`（走進去換地圖，`tx/ty` 是落點）。
- 城鎮：`houses`（矩形障礙）、`npcs`（`open` 指定點了開哪個視窗）、`spawn` 出生／復活點。
- 障礙物：`buildObstacles(id)` 用種子亂數產生樹與石頭（同一張圖每次一樣），避開傳送點、練功區、道路。`blocked()` 做碰撞。
- 怪物數值 `monsterStats(lv, isBoss)`：氣血 `(56+34lv)·1.035^lv`、攻擊 `(10+5.6lv)·1.02^lv`；首領氣血 ×10、攻擊 ×1.6。
- 新增地圖：在 `MAPS` 加一筆、`MAP_ORDER` 加 id、前一張圖加傳送點。

## 7. 裝備與丹藥（items.js）

- 五部位：兵器（刀／槍／爪，`wtype`）、衣甲、頭冠、靴履、佩飾；每 10 級換一階名稱。
- 品質：凡品／良品／精品／絕品／神品（倍率 1～2.8），良品以上有副屬性。
- 掉落：一般怪 10%、首領必掉精品以上。可設定擊殺時自動賣出某品質以下。
- 強化（城鎮鐵匠）：+0～+10，成功率 100%→20%，+7 以上失敗掉一級；每級主屬性 +8%。**兵器 +5 以上人物身上會發光**。
- 丹藥：金瘡藥（氣血 30%）、回氣丹（真氣 35%），共用 1 秒冷卻，可設定自動用藥門檻。

## 8. 存檔與離線（state.js）

- `SAVE_KEY = 'langji_jianghu_save_v2'`；每 10 秒、關頁、切到背景時存檔；所有 localStorage 都包 try/catch。
- 改存檔結構時在 `migrateSave` 補欄位。
- 匯出／匯入：base64 JSON 字串（設定視窗）。
- 離線收益：離線前在野外**開著掛機**才有；以「目前地圖中等級 ≤ 玩家＋2 的最高練功區」估算，效率 50%、最多 8 小時；打不贏就沒有；經驗最多給 3 級份量。

## 9. 世界與移動（world.js）

- `enterMap(id, x, y)`：重建 `W`（怪物、目標、聚氣清空，冷卻與增益保留）。
- 點擊（`clickWorld`）：先找怪（攻擊）→ 再找 NPC（走過去開視窗）→ 否則走到該點。點小地圖也會走過去（直線＋繞路，沒有尋路演算法）。
- `stepToward`：直走 → 只走 x → 只走 y → 斜前方／側面繞路；完全卡住才停。
- `chaseCheck`：追同一目標 3 秒都沒更靠近就放棄，並忽略那隻怪 8 秒（用遊戲時間 `W.time`）。
- 怪物 AI：閒置 ↔ 在練功區內遊走；主動怪 150px 內會追；被打一定追；離家超過「半徑＋350」就回家並回滿血。內功怪在 200px 外就會出手。
- 自動練功（`autoHuntPick`）：找最近、等級 ≤ 玩家＋3 的怪（正在打我的優先），首領要等級夠才打；沒怪就走向合適的練功區。`AUTO_HUNT_LV` 控制開放等級（目前 1）。
- 城鎮回血回氣 8 倍。重傷 5 秒後回柳溪鎮。

## 10. 戰鬥（combat.js）

- 普攻：目標在兵器射程內就依出手間隔自動攻擊。
- `useSkill(id)`：檢查是否學會、門派／兵器是否相符、冷卻、真氣；距離不夠就記在 `W.queued`，走進射程後自動放。
- 有 `cast` 的武學先進入 `W.casting` 讀條（不能移動，點地面移動會取消），讀完才 `castSkill`。
- 掛機時（勾「自動施放」）依快捷欄順序施放可用武學；回血技在氣血 > 60% 時不放，增益技還在時不重放。
- 擊殺：經驗、銀兩、修為、掉落；一般怪 8 秒重生。

## 11. 畫面繪製（render.js）

- 地面（底色斑塊、道路、城鎮廣場、小草）每張地圖畫一次到離屏 canvas（`MAPS[id].bg`）。
- 每幀：傳送陣 → 樹／石／房屋／NPC／怪物／玩家依 y 排序繪製（只畫畫面內）→ 飄字與範圍圈 → 小地圖。
- 玩家：`avatarImage(G)` 圖片，依面向左右翻轉；走路上下晃、出手前衝、受傷後退、重傷倒地、聚氣時腳下光圈與讀條。
- 怪物目前用 emoji（之後可換圖）；名牌顏色依等級差（紅＝高很多、橘＝略高、灰＝低很多）。
- 畫布是絕對定位（不能撐開版面，否則手機版會被撐寬）。

## 12. 介面（ui.js）

- HUD：氣血／真氣／經驗條、銀兩、修為、目標框、增益、小地圖、訊息。
- 快捷欄 8 格（鍵盤 1～8）：可放武學或丹藥，在「武學」視窗用下拉指派。
- 視窗（`PANELS`）：角色、武學、行囊、地圖、設定；NPC 視窗：藥鋪 `shop`、鐵匠 `smith`、武館 `outer`、驛站 `travel`（付銀兩直達各地圖入口）。
- 鍵盤：1～8 快捷欄、H 掛機、C 角色、K 武學、B 行囊、M 地圖、Esc 關視窗。
- 確認框用 `gameConfirm`，不要用原生 `confirm`／`alert`。

## 13. 人物外觀（avatar.js）

- 原創 SVG：門派決定服裝與髮型（玄霄觀道髻、鐵衣門頭巾、百草谷髮花、無影樓兜帽面巾），性別、髮色 5 種、膚色 4 種在建角與角色視窗可改。
- 裝備反映在外觀：兵器種類（刀／槍／爪）、衣甲品質＝衣服滾邊色、頭冠、靴子顏色、佩飾＝身後光環、兵器 +5 以上發光。
- `avatarImage(p)` 依外觀與裝備產生快取 key，變了才重做圖片。

## 14. 數值模擬結果（20261102i 版）

在瀏覽器裡用 `worldTick` 快轉，自動換裝、升武學、補藥、換地圖，掛機 3 小時：

| 門派 | 3 小時等級 | 重傷次數 |
|---|---|---|
| 玄霄觀 | 23 | 16 |
| 鐵衣門 | 21 | 0 |
| 百草谷 | 23（舊數值） | 0 |
| 無影樓 | 26（舊數值） | 0 |

已知問題：銀兩只進不出（3 小時累積數萬兩），需要更多花費管道。
