# PC 原版還原核對

本次將 Map 0、Map 4 改為直接繪製原始 SEG／S32／TIL。原始像素與角色使用相同比例，不再用合成地圖加跨來源室內補丁。圖層、屋頂事件、遮擋事件與半格通行資料取自相同地圖檔。

## 已安裝

- 663 個原始地圖區塊、374,592 個原始 TIL 區塊。
- PC 場景原生像素 1:1，固定鏡頭跟隨。
- 全圖原始通行資料與 Map 4 尋路連通區。
- Map 0／4 原始生成數量、群落、血魔、攻速、移速、主動及反擊設定。
- 250 組 NPC／怪物外觀、完整掉落表 12,839 筆。
- NPC／怪物原始回血回魔間隔；伺服器經驗倍率保留 2 倍。
- 全 DB 設定資料可透過「source-review.html」搜尋核對。
- 原始核心 2,686 個 class 與 110 個設定值的來源對照，存於 data/native-core-reference.json。

## 地圖載入（2026-11-09）

- 問題：進地圖時畫面先是放大的模糊全島縮圖、角色被蓋住且不能動，要等 30～70 張原始圖集（13～28 MB）全部下載才出現原始地圖。
- 原因：畫面需要的原始 TIL 區塊分散在很多張 2048×2048 圖集裡，一個畫面平均每張圖集只用到幾十塊。
- 處理：新增 `assets/native-world/lite/` 輕量底圖（每頁約 150 KB），載入期間立即顯示清楚場景；載入底圖改放在角色／怪物下層，載入期間允許移動（通行仍用原始資料）。原始圖集讀完後換回原始地圖，已實測兩者位置吻合。
- 驗證：以模擬慢速網路（圖集延遲 8 秒）測說話之島與大陸，載入中畫面清楚、角色可見可移動，Console 無新錯誤。
- 圖集切小頁（同日）：原本 2048×2048（1024 塊）一張，一個畫面平均要下載 16 MB；模擬發現畫面裡 67% 是全圖重複使用的地面材質，重新排序幫助有限（36.7→約 31 張），改成切成 512×512（8×8＝64 塊）小頁、編號不變，平均降到約 3.6 MB（約 130 個小檔，HTTP/2 同時下載）。
  - 新檔：`assets/native-world/manifest-atlas64.json`（多 `atlasTiles`、`atlasColumns`）＋ `atlas64/p-N.png`（含 file:// 用的 .png.js），舊 `atlas-N.png` 與 `manifest.json` 已刪除。
  - 程式：`data/native-world.js` 與 worker 的頁大小改讀 manifest（PER／COLS），區塊 JSON 不變。
  - 工具：`tools/atlas-split/split.js`（Node 內建 zlib，像素逐位元組比對 0 差異）。
