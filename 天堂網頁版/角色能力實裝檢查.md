# 角色能力實裝檢查（2026-11-15）

本次核對的是實際戰鬥公式與呼叫路徑，沒有擅自改動戰鬥平衡。

| 項目 | 現況 | 實際作用 |
| --- | --- | --- |
| 防禦 AC | 已生效 | 等級、敏捷、裝備 AC／強化、套裝、變身及技能加成進入怪物命中與物理減傷計算。 |
| 抗魔 MR | 已生效 | 等級、精神、職業、裝備、套裝、變身及技能加成降低怪物魔法傷害；不是免疫機率。 |
| 固定物理／魔法減傷 | 已生效 | 裝備、套裝、變身及技能減傷在怪物傷害結算中扣除。 |
| 迴避修正 | 已生效 | 道具及技能修正進入怪物攻擊命中擲骰；沒有不依敵人變動的固定迴避百分比。 |
| 體質 CON | 部分生效 | 初始體質影響升級 HP 成長；當前體質影響自然回血。 |
| 精神 WIS | 部分生效 | 初始精神影響升級 MP 成長；當前精神影響自然回魔、MR。 |
| 敏捷 DEX | 部分生效 | 已影響 AC；尚未接入玩家遠距離傷害與命中。 |
| 力量 STR | 未完整生效 | 能力欄會加總裝備與技能數值；玩家近距離傷害尚未引用 STR。負重顯示有引用 STR／CON，但背包交易沒有完整超重限制。 |
| 智力 INT | 未完整生效 | 能力欄會顯示加總值；攻擊魔法、治癒量與技能 MP 消耗未引用 INT。 |
| 魅力 CHA | 已生效於召喚容量 | 召喚系統以 CHA + 6 減去現有召喚消耗，限制可召喚數量；召喚控制戒指也檢查魅力。 |
| 武器傷害、強化及直接傷害加成 | 已生效 | 玩家普攻採武器隨機傷害、職業等級加成、裝備／套裝／變身／技能直接加成及觸發傷害。 |
| 玩家近／遠距離命中 | 尚無命中擲骰 | 有效攻擊直接命中，怪物 AC 尚未用於玩家普攻結算。 |
| 魔攻 SP | 未完整生效 | 會加總並顯示；目前玩家攻擊魔法仍使用技能原始骰數傷害。 |
| 魔法暴擊、智力省魔、創角智力省魔 | 未實裝 | 魔法沒有暴擊分支；施法按技能原始 MP 扣除。 |
| 火、水、風、地屬性抗性 | 未實裝 | 怪物魔法結算未引用元素抗性，能力欄已標示「未套用」。 |

主要依據：`data/native-combat-rules.js`、`data/island-npc-ai.js`、`data/island-combat.js`、`data/player-class-stats.js`、`data/player-growth.js`、`data/player-skills.js`、`data/owned-inventory.js`、`data/summons.js`。

新增回歸測試 `tools/combat-stats.test.cjs`：驗證敏捷／等級與裝備改變 AC、精神與裝備改變 MR，並實際比較命中、物理減傷及魔法傷害結果。範例：100 點怪物魔法傷害在 MR 0 時為 100，MR 100 時為 50；再加 20 點魔法減傷後為 40。
