# 天堂網頁版開發與操作

入口為 ../index.html；所有遊戲功能腳本放在 data/，由入口依相依順序載入。
- core.js / player.js：共用工具、角色狀態。
- notifications.js / panels.js：提示、背包、設定與職業選擇。
- combat.js / input.js：戰鬥展示、鍵盤與方向按鈕。
- talking-island-data.js / island-scene-data.js：通行資料與場景分頁排列。
- scene-renderer.js：地圖繪製、碰撞、固定角度／倍率的跟隨鏡頭、位置保存。
- navigation.js：點地座標轉換、尋路、目的地標記。
- mobile-controls.js：觸控／滑鼠、長按、手勢隔離。
- rpg-hud.js：操作介面、小地圖、快捷欄。
- character-data.js / character-renderer.js：四職業男女、八方向人物影格與動畫。

目前操作方式：
- 鏡頭角度、倍率固定，自動跟隨人物。不能手動拖曳地圖或縮放。
- 點擊／輕觸地面走到目的地；按住或拖動控制人物，放開停止。
- 行走只受原始地圖通行資料限制，不以目前畫面邊界限制活動。
- 手機轉向重新適配版面，不重設人物座標。
- 方向按鈕與鍵盤仍可使用，開啟選單或離開頁面會停止移動。

新增功能請另建 JS，並在 index.html 依相依順序加入 script defer，更新 v 版本參數。
樣式在遊戲根目錄 mobile.css、rpg-hud.css；地圖與人物圖片在 assets/。
此遊戲目前為本機展示，未接遊戲伺服器。場景和人物來自使用者本機既有素材，原始來源未修改。

入口流程：
1. 310.png 登入背景：填入測試帳號與密碼。
2. load.png 人物選擇背景：選擇四職業、性別與名稱。
3. 確認後進入說話之島；登入／選角時場景操作鎖定。
entry-flow.js 管理三階段流程；entry-screens.css 負責入口版面；圖片在 assets/entry/。
目前登入只驗證欄位已填寫，並非正式帳號驗證。沒有儲存或傳送密碼，請使用測試帳密。
角色圖片來源：使用者本機 idle-lineage-class-20260825-1924/assets/start；登入背景來源 public/assets/login。

角色建立與保存（目前流程）：
- 新測試帳號登入後是四個空角色欄位，沒有預先建立的四職業人物。
- 點空欄位或「建立角色」進入獨立創角頁；使用原始 824.png 作背景。
- 提供職業基本介紹、性別、角色名稱，以及六項能力的加減／重置配點。
- 初始能力與可分配點數依 C_CreateChar.java；六項能力總和必須為 75。
- 騎士 4 點、法師 16 點、王族 8 點、妖精 7 點；上限依該伺服器的初值加配點額度，未自行套用 18 點上限。
- 初始 HP／MP 依 CalcInitHpMp.java；選定人物後套用到角色與血魔條。
- class-creation-data.js：職業介紹、初始值、配點規則與生命魔力計算。
- character-creation.js / character-creation.css：創角畫面與手動配點操作。
- character-store.js：依測試帳號保存於目前瀏覽器，不保存密碼；尚未接 SQL 帳號／角色資料庫。
- 已建立角色才會顯示在選角畫面；創角確認後仍需選取角色並按進入遊戲。

移動速度（依使用者原始變身資料）：
- sprite-movement-data.js 保存 TW13032701.txt 的動作影格、停留時間，並以 db/363.sql 的 spr_action 核對。
- 依 SprTable.java：毫秒 = 時間單位總數 × 40 × (24 / frameRate)。八種男女角色普通走路都是 16 單位、frameRate 24，因此未加速為 640ms 一格。
- 四個走路姿勢各停留 160ms；女法師素材有八張，依變身檔使用第 0、2、4、6 張，其他角色使用第 0、1、2、3 張。
- movement-config.js 共用速度限制；滑鼠連點、鍵盤重複事件不能加速。每一步開始時固定該步時長，避免中途切換狀態造成跳動。
- 保留 AcceleratorChecker.java 的加速倍率及逐次取整規則，尚未啟用任何加速狀態；防外掛寬限值不當作移動速度。

平滑走路：
- 顯示座標以 requestAnimationFrame 按同一個步伐時間表在格與格之間連續內插。
- 鏡頭與人物使用相同顯示座標，不再每格瞬間跳動。
- 連續尋路在上一段動畫完成時接續下一段，避免等待輪詢造成停頓。
- 走路影格按時間取樣，預載最近四組人物方向素材；場景圖片以非同步方式解碼。
- 走路時存檔最多每秒一次，停下時再保存，避免每幀寫入本機儲存。
