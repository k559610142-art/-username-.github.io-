使用內建 image_gen，依原有初行俠客參考圖重製。八個方向分開生成，每張為4欄×2列、八個完整人物姿勢。未使用鏡像方向替代。

目標循環順序：左腳觸地、左腳承重、右腳過腿、右腳前伸、右腳觸地、右腳承重、左腳過腿、左腳前伸。生成圖增加不同色的腳踝綁帶，協助觀察雙腳；綁帶細節仍可能有生成誤差，檢查以腿部位置、膝蓋及鞋底動作為主。

data/walk-frames/*.js 只保存來源座標與軀幹／地面定位，不修改PNG。以完整人物影格繪製，不使用拼接腿部。新版八格對應16個時間單位；沿用已記錄的640ms基準，Shift依0.755倍時長同步加快。

頁面可暫停八方向同步預覽並逐格查看。上述來源設定只作時序參考，不宣稱匯入原遊戲SPR動畫。

自動驗證：`node tools/test-character-animation.mjs` 檢查八個獨立來源、64格來源範圍、不使用方向鏡像、128個時序繪製取樣，以及位移和動作的640ms同步。自動檢查不判斷人體步態是否自然；圖片仍另做視覺檢查。

視覺檢查：前後半循環的前伸腿、鞋底、膝蓋與反向擺臂；嚴格背面方向另外使用手繪腳位參考修正，防止以交換綁帶顏色冒充換腳。腳位參考位於 reports/walk-n-pose-guide.png，並非遊戲素材。
